# Personal Coach Types

Seven coach archetypes available for selection during onboarding.
Each maps to a coaching style injected into the AI prompt context.

| # | Coach Type | Focus |
|---|-----------|-------|
| 1 | **Strength & Conditioning Coach** | Barbell lifts, progressive overload, strength fundamentals |
| 2 | **Bodybuilding Coach** | Hypertrophy, muscle isolation, aesthetics, volume |
| 3 | **Athletic Performance Coach** | Power, speed, sport-specific conditioning |
| 4 | **Fat Loss & Conditioning Coach** | Metabolic conditioning, HIIT, caloric burn |
| 5 | **Functional Fitness Coach** | CrossFit-style, GPP, varied movements |
| 6 | **Endurance & Cardio Coach** | Running, cycling, rowing, aerobic base building |
| 7 | **Mobility & Recovery Coach** | Flexibility, corrective work, injury prevention |

## Prompt Injection Format
When generating workouts, the coach type is prepended to the user prompt:
> "As my [Coach Type], generate a workout that fits my goals..."
