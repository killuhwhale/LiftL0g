# User Fitness Profiles

Preset fitness level + interest combos presented during onboarding (step 3).
User picks one. Used to calibrate AI workout complexity and volume.

| # | Profile | Prompt Context |
|---|---------|----------------|
| 1 | **Beginner — Just Getting Started** | New to exercise, focus on form and basic movements |
| 2 | **Beginner into Bodybuilding** | New but motivated to build muscle and learn splits |
| 3 | **Intermediate — Training 1-2 Years** | Comfortable with main lifts, looking to progress |
| 4 | **Intermediate into Strength Sports** | Pursuing powerlifting or Olympic lifting |
| 5 | **Advanced Lifter — 3+ Years** | Experienced, high volume and intensity capable |
| 6 | **Competitive Athlete** | Sport-specific, performance over aesthetics |
| 7 | **Functional Fitness / CrossFit** | Varied modalities, gymnastics, metcons |
| 8 | **Active Senior (50+) — Low Impact** | Joint-friendly, mobility-focused, sustainable training |

## Prompt Injection Format
> "My fitness background: [Profile description]."
