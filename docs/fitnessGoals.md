# Fitness Goals

Top 7 fitness goal categories presented during onboarding.
Users can select up to 3. Goals are included in AI prompt context.

| # | Goal | Description |
|---|------|-------------|
| 1 | **Build Strength** | Increase 1RM on compound lifts. Progressive overload focus. |
| 2 | **Gain Muscle** | Hypertrophy-focused training. Volume and time under tension. |
| 3 | **Lose Fat** | Metabolic conditioning, caloric burn, body recomposition. |
| 4 | **Athletic Performance** | Power, speed, agility. Sport-specific carry-over. |
| 5 | **Increase Endurance** | Aerobic capacity, stamina, conditioning base. |
| 6 | **Improve Mobility** | Flexibility, range of motion, corrective exercise. |
| 7 | **General Health** | Balanced fitness, longevity, overall well-being. |

## Prompt Injection Format
> "My fitness goals are: [Goal 1], [Goal 2], [Goal 3]."
